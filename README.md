# Task1CSpec

Task1CSpec - Codex-плагин для ведения задач 1С через последовательные спецификации. Он хранит материалы задачи в `ProjectSpecs`, проводит работу по ролям, переносит завершенные задачи в архив и помогает обновлять проектную документацию.

Подход вдохновлен OpenSpec, но вместо `changes` используются задачи.

## Структура

```text
ProjectSpecs/
  Архив/
  Документация/
  Задачи в работе/
commands/
skills/
scripts/
```

## Использование в Codex

Плагин добавляет команды:

- `/TaskStart <номер-задачи>: <название-задачи>`
- `/TaskAnalyst <номер-задачи>`
- `/TaskArchitect <номер-задачи>`
- `/TaskDeveloper <номер-задачи>`
- `/TaskTester <номер-задачи>`
- `/TaskTechWriter <номер-задачи>`

Также есть русские алиасы:

- `/TaskАналитик <номер-задачи>`
- `/TaskАрхитектор <номер-задачи>`
- `/TaskРазработчик <номер-задачи>`
- `/TaskТестировщик <номер-задачи>`
- `/TaskТехническийПисатель <номер-задачи>`

Если Codex показывает команды плагина с namespace, используйте такой формат:

```text
/task1cspec:TaskStart RTD-2343: Доработка переключения вызова из ОМ ВнешниеДанные. ТоварныеОперации
```

Манифест плагина находится в `.codex-plugin/plugin.json`.

## Процесс

1. `/TaskStart` находит существующую задачу по номеру или после подтверждения создает новую папку в `ProjectSpecs/Задачи в работе/`.
2. Роли выполняются последовательно: аналитик, архитектор, разработчик, тестировщик, технический писатель.
3. Каждый этап читает уже созданные спецификации, уточняет недостающую информацию, создает свой файл и останавливается на проверку.
4. Код можно менять только после утверждения спецификации `Реализация.md`.
5. На этапе технического писателя проектная документация обновляется до архивации, а перенос задачи в `ProjectSpecs/Архив/` выполняется только после отдельного подтверждения.

## Файлы спецификаций

- `ТехЗадание.md`
- `Архитектура.md`
- `Реализация.md`
- `Тест-кейсы.md`
- `Документация по задаче.md`

## CLI-помощник

Плагин содержит небольшой помощник для работы с папками и стартовыми файлами:

```bash
python3 scripts/task1cspec.py init
python3 scripts/task1cspec.py start "RTD-2343: Доработка переключения вызова"
python3 scripts/task1cspec.py status RTD-2343
python3 scripts/task1cspec.py role Аналитик RTD-2343
python3 scripts/task1cspec.py archive RTD-2343
```

CLI управляет только структурой папок, статусами и стартовыми файлами. Агент отвечает за вопросы пользователю, чтение предыдущих спецификаций, анализ кода 1С, создание содержательной спецификации и остановку на проверку.

## Установка

Это самостоятельный Codex-плагин. Для установки используйте корень этого репозитория как источник плагина; дополнительных адаптеров для других агентов в проекте нет.
