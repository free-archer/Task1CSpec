# Шаблоны спецификаций Task1CSpec

Шаблоны разделены по файлам. Перед созданием или обновлением спецификации читай шаблон только для текущей роли.

| Роль | Файл результата | Шаблон |
|---|---|---|
| Аналитик | `ТехЗадание.md` | `templates/analyst.md` |
| Архитектор | `Архитектура.md` | `templates/architect.md` |
| Разработчик | `Реализация.md` | `templates/developer.md` |
| Тестировщик | `Тест-кейсы.md` | `templates/tester.md` |
| Технический писатель | `Документация по задаче.md` | `templates/techwriter.md` |

Обязательные разделы и имена файлов результата должны остаться неизменными.
